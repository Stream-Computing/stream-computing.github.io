设备管理系统使用指南（系统管理员）

随着人工智能的跨越式发展和数字化转型的提速，各行各业对优质算力的需求也水涨船高，千卡乃至万卡集群纷纷拔地而起。智算中心的火热建设也伴随着高效管理大规模物理设备的需求，传统单机BMC依赖管理员自行维护服务器的信息，不够标准化，且每次配置都需要重复登录服务器的操作，操作碎片化，进而导致运维效率低下，故障处理迟缓。希姆计算针对这些痛点推出了BMC设备管理系统，为客户提供大规模物理设备的高效管理方案。

BMC设备管理系统在传统单机BMC的基础上，围绕服务器构建了一站式的物理设备管理平台，汇总了服务器以及相关的机架、布线等关键物理设备的信息，方便用户一站式管理智算中心内各种物理设备。

准备工作​

  • 确认希姆云平台已部署完毕，能够正常访问登录页面。

  • 获取云管平台系统管理员账号和密码。

典型使用流程​

管理员规划和运维物理设备的典型流程如下：

  1. 登录BMC设备管理系统。

  2. 添加机架。

  3. 添加服务器。

  4. 添加网络设备。

  5. 将服务器、网络设备上架到机架。

  6. 添加服务器到带外交换机的布线信息。

  7. 日常监控服务器内部重要组件的状态。

登录设备管理系统​

  1. 访问希姆云平台登录页面。

  2. 输入系统管理员账号和密码。

  3. 输入验证码。

  4. 单击登录。

  5. 单击设备管理。

  6. 查看设备总览。BMC设备管理系统总览页统计了已添加所有物理设备的数量、服务器类型比例和各类型服务器上架情况，并展示了当日的操作日志，方便您全面了解物理设备资产的构成以及当日的操作记录。

管理机架​

在机架管理页面添加并维护智算中心内所有机架的信息，并完成上架和下架服务器和网络设备的操作。

  1. 在左侧导航栏中，选择机架管理 > 机架列表。

  2. 单击新增。

  3. 填写机架信息。

    机架信息描述
    机架编号机架的唯一标识，新增成功后不可修改。
    机架高度机架可以容纳服务器的总高度，以机架式设备的通用高度单位U为标准，新增成功后不可修改。
    机架位置机架在智算中心中的位置。

  4. 单击新增。

  5. 机架添加成功后会显示在列表中，您可以按需管理。

    • 单击详情，管理当前机架中的服务器。

    • 单击编辑，编辑当前机架的信息，仅支持修改机架位置和备注信息。

    • 单击删除，删除当前机架的信息。

    • 单击下架所有服务器，将机架上的所有服务器都置为下架状态。

  6. 将服务器或网络设备上架到当前机架。

    1. 单击详情。

    2. 单击上架服务器。

    3. 选择待添加的服务器或网络设备。

      说明：请确保已经添加了服务器或网络设备。

    4. 填写该服务器或网络设备在机架上的起始位置。

      注意：上架到机架的服务器和网络设备总高度不得超过机架高度，也不能选择已被占据的位置，否则会上架失败。

    5. 单击确定。

    6. 服务器或网络设备上架成功后，机架详情中以表格形式直观展示机架中所有服务器和网络设备的位置以及占据的高度。您可以按需下架单台服务器或网络设备，也可以在机架管理页面一键下架所有服务器和网络设备。

管理服务器​

管理服务器列表​

在服务器管理页面添加和维护智算中心内所有算力、管理、存储服务器的信息，并完成上架和下架服务器的操作。

  1. 在左侧导航栏中，选择服务器管理 > 算力服务器，或者服务器管理 > 管理服务器，或者服务器管理 > 存储服务器。

  2. 单击新增。

  3. 填写服务器信息。

    服务器信息描述
    主机名标识服务器以便规范管理的名称，建议使用具有规范含义的名称，例如城市-楼号-企业-编号。
    资产编号在组织内进行资产盘点时为服务器指定的编号。
    供应商供应服务器并承担售后服务的厂商。
    设备型号服务器的出厂型号。
    序列号出厂时标识服务器的唯一编号。
    BMC网络配置在带外管理网络中为服务器分配的IP地址等标识信息。
    服务器高度服务器的高度，以机架式设备的通用高度单位U为标准，新增成功后不可修改。

  4. 单击新增。

  5. 服务器添加成功后会显示在列表中，您可以按需管理。

    • 单击详情，重启或关闭当前服务器，查看当前服务器的系统标识信息，以及处理器、内存、基板、电源、风扇、GPU等服务器内部信息。

      说明：需要提前输入登录服务器的账号密码，才能查看到服务器的内部信息。

    • 单击编辑，编辑当前服务器的信息，不支持修改服务器高度。

    • 单击登录配置，编辑当前服务器的登录账号，获取处理器、内存等服务器内部信息。

    • 单击删除，删除当前服务器。

    • 单击上架，将当前服务器上架到指定机架。

      注意：上架到机架的服务器和网络设备总高度不得超过机架高度，也不能选择已被占据的位置，否则会上架失败。

    • 单击下架，将当前服务器从所在机架上置为下架状态。

管理单台服务器​

重启或关闭服务器​

在服务器管理页面中远程重启或关闭服务器，降低现场维护的次数，提升维护效率。

说明：目前仅支持远程重启或关闭算力服务器，管理、存储服务器相关设备在协调中。

  1. 在左侧导航栏中，选择服务器管理 > 算力服务器。

  2. 定位到待重启或关闭的算力服务器，单击登录配置，输入登录服务器的账号密码。

  3. 单击详情，进入算力服务器的详情页面。

  4. 重启或关闭算力服务器。

    • 如需重启算力服务器，单击硬重启，然后单击确定。

    • 如需关闭算力服务器，单击关闭电源，然后单击确定。

查看服务器内部信息​

在服务器管理页面中查看服务器内部重要组件的信息以及状态，方便日常监控和出现问题时精准定位故障组件。

说明：目前仅支持远程查看算力服务器的内部信息，管理、存储服务器相关设备在协调中。

  1. 在左侧导航栏中，选择服务器管理 > 算力服务器。

  2. 定位到待重启或关闭的算力服务器，单击登录配置，输入登录服务器的账号密码。

  3. 单击详情，进入算力服务器的详情页面。

  4. 按需查看当前服务器的系统标识信息，以及处理器、内存、基板、电源、风扇、网卡、GPU等服务器内部信息。

    • 单击系统，查看服务器在BMC设备管理系统中的标识信息，以及服务器内部系统的信息。

      系统信息描述
      主机名标识服务器以便规范管理的名称，建议使用具有规范含义的名称，例如城市-楼号-企业-编号。
      资产编号在组织内进行资产盘点时为服务器指定的编号。
      供应商供应服务器并承担售后服务的厂商。
      设备型号服务器的出厂型号。
      序列号出厂时标识服务器的唯一编号。
      BMC网络配置在带外管理网络中为服务器分配的IP地址等标识信息。
      服务器高度服务器的高度，以机架式设备的通用高度单位U为标准，新增成功后不可修改。
      所在机架编号服务器上架至的机架。
      机架位置服务器所在机架在智算中心中的位置。
      在机架起始位置(单位：U)服务器放置在机架上时底部所在位置。
      在机架终止位置(单位：U)服务器放置在机架上时顶部所在位置。
      系统名称服务器系统信息名称。
      系统描述服务器系统信息描述。
      系统模组服务器模组型号。
      系统制造商制造该服务器的公司或品牌。
      系统序列号设备的唯一标识符，可用于唯一识别该设备。
      系统类型服务器的系统类型。
      BIOS版本服务器的BIOS版本。
      状态设备的当前状态。
      UUID设备的唯一通用唯一标识符，通常用于唯一标识计算机或服务器。

    • 单击处理器，查看服务器所有在位的处理器的信息，包括：

      • 标识信息：ID、名称、制造商

      • 规格信息：类型、型号、架构、总核数、最大频率MHz

      • 状态信息：是否处于正常工作状态

    • 单击内存控制器，查看服务器内存的信息，包括：

      • 标识信息：名称、制造商、序列号、零件号

      • 规格信息：内存类型、容量MiB、最大频率MHz

      • 状态信息：是否处于正常工作状态

    • 单击基板，查看服务器基板信息和网络界面信息，包括：

      • 基板标识信息：名称、描述

      • 基板规格信息：模组、固件版本

      • 基板状态信息：基板是否处于正常工作状态、基板电源是否已打开

      • 网络界面标识信息：名称、MAC位址、IPv4位址、主机名

      • 网络界面状态信息：接口是否已启用、网络界面是否处于正常工作状态

    • 单击电源，查看服务器电源控制信息，包括：

      • 标识信息：名称、制造商

      • 规格信息：型号、固件版本、额定功耗（W）、序列号

      • 状态信息：当前输出功耗（W）

    • 单击风扇，查看服务器风扇信息，包括：

      • 标识信息：风扇名称

      • 规格信息：规格型号、最大读数范围

      • 状态信息：风扇是否处于正常工作状态、风扇的实时每分钟转数Reading(RPM)、风扇的实时占空比

    • 单击网卡，查看服务器网卡的信息，包括：

      • 标识信息：编号、名称、位置、MAC1地址、MAC2地址、MAC3地址、MAC4地址

      • 规格信息：网卡类型、接口类型、端口数量、固件版本

      • 状态信息：网卡是否处于正常工作状态

    • 单击GPU，查看服务器所有在位的GPU加速卡的信息，包括：

      • 标识信息：槽位、名称、描述、厂商ID/设备ID、SVID/SSID、序列号

      • 规格信息：固件版本

      • 状态信息：GPU的实时温度（℃）、实时功耗（W）

    • 单击存储装置，查看服务器存储装置驱动信息和硬盘状态信息，包括：

      • 存储装置驱动的标识信息：名称、制造商、序列号

      • 存储装置驱动的规格信息：协议、固件版本、媒体类型、容量（GB）、型号

      • 存储装置驱动的状态信息：实时传输速率（Gb/s）、实时机械转速（RPM）

      • 硬盘的标识信息：硬盘背板、硬盘槽位

      • 硬盘的规格信息：硬盘类型

      • 硬盘的状态信息：硬盘是否正常在位、是否发生重建引导、是否出现硬盘错误

管理网络设备​

在网络设备页面添加并维护智算中心内带外交换机等网络设备的信息，并完成上架和下架网络设备的操作。为避免影响业务网络性能，提升物理设备管理的可靠性，一般采用管理数据和业务数据分链路传输的带外管理方式，配备专门的带外交换机。

  1. 在左侧导航栏中，选择网络设备管理 > 网络设备。

  2. 单击新增。

  3. 填写网络设备信息。

    服务器信息描述
    主机名标识网络设备以便规范管理的名称，建议使用具有规范含义的名称，例如城市-楼号-企业-编号。
    资产编号在组织内进行资产盘点时为网络设备指定的编号。
    供应商供应网络设备并承担售后服务的厂商。
    设备型号网络设备的出厂型号。
    序列号出厂时标识网络设备的唯一编号。
    设备网络在带外管理网络中为网络设备分配的IP地址等标识信息。
    设备高度网络设备的高度，以机架式设备的通用高度单位U为标准，新增成功后不可修改。

  4. 单击新增。

  5. 网络设备添加成功后会显示在列表中，您可以按需管理。

    • 单击详情，查看当前网络设备在BMC设备管理系统中的标识信息。

    • 单击编辑，编辑当前网络设备的信息，不支持修改设备高度。

    • 单击删除，删除当前网络设备。

    • 单击上架，将当前网络设备上架到指定机架。

      注意：上架到机架的服务器和网络设备总高度不得超过机架高度，也不能选择已被占据的位置，否则会上架失败。

    • 单击下架，将当前网络设备从所在机架上置为下架状态。

管理布线​

在布线管理页面添加并维护物理设备之间的互联信息。

  1. 在左侧导航栏中，选择布线管理 > 布线管理。

  2. 单击新增。

  3. 填写布线信息。

    1. 选择源设备并填写互联使用的端口。

    2. 选择目标设备并填写互联使用的端口。

  4. 单击新增。

  5. 布线添加成功后会显示在列表中，您可以按需管理。

    • 单击更新，编辑当前布线的信息。

    • 单击删除，删除当前布线信息。

管理日志​

实时记录并在日志管理页面展示所有用户操作的详细日志，便于审计操作行为，满足审计追溯和系统合规的需求。

  1. 在左侧导航栏中，选择日志管理 > 日志管理。

  2. 日志管理页面显示了BMC设备管理系统的资源操作记录，日志中包含了操作时间、操作类型、操作的资源对象以及操作时填写的备注。

    • 如果需要搜索某种操作类型和某段时间范围的操作记录，在页面上方选择操作类型以及时间范围，然后单击查询。

    • 如果需要删除某条日志，单击删除并按提示完成操作即可。

管理用户​

在用户管理页面添加并维护多个管理员账号，方便多人共同管理物理设备。

  1. 在左侧导航栏中，选择系统设置 > 用户管理。

  2. 单击新增。

  3. 填写用户信息。

    • 必选信息：账号、密码。账号和密码用于登录BMC设备管理系统。

    • 可选信息：昵称、手机号、邮箱、备注信息。

  4. 单击新增。

  5. 用户添加成功后会显示在列表中，您可以按需管理。

    • 单击详情，查看当前用户的详细信息。除添加用户时填写的信息外，还包括了用户状态、创建时间、更新时间、更新人等。

    • 单击编辑，编辑当前用户的信息。仅支持修改昵称、手机号、邮箱、备注信息。

    • 单击修改密码，修改当前用户的登录密码。

    • 单击删除，删除当前用户。
